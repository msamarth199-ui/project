CHETAN REDDY PORTFOLIO
======================

Files:
- index.html  : portfolio page and Bootstrap 5 CDN links
- style.css   : custom responsive dark-theme styling
- script.js   : mobile navigation behavior, current year, scroll spy

Preview:
1. Keep all files in the same folder.
2. Open index.html in a modern browser. Internet access is needed for Bootstrap and Google Fonts CDN resources.
3. Replace example@gmail.com, the generic LinkedIn URL, and xyz education placeholders in index.html.
4. Add a GitHub repository or live demo URL for the Django project when available.

Deploy:
- GitHub Pages: upload all three files to a repository and enable Pages in repository settings.
- AWS S3: upload the files to a bucket configured for static website hosting, or use CloudFront for HTTPS delivery.
